Dotfiles
========

##### A directory containing my config files.

### Some common apt packages to install

```
sudo apt install tldr
```

### Some common cargo packages to install

```
cargo install --locked --bin jj jj-cli
cargo install --locked zellij
cargo install --locked bat
cargo install eza
cargo install selene
```

### Some common nix packages to install

```
nix-env -iA nixpkgs.grim
nix-env -iA nixpkgs.slurp
```
